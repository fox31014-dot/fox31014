# 家庭问题分析系统 · 报告生成核心原则

本文件定义了**根据问卷答案生成分析报告**时必须遵守的核心原则。任何分析引擎、AI prompt、报告模板都应符合这些规则。

---

## 1. 双层信息架构

问卷答案在分析时需要拆成两层使用：

### Layer A：可外显信息（可直接出现在报告中）
- 孩子的行为观察（睡眠、饮食、运动、屏幕、注意力、情绪、学习习惯等客观描述）
- 家庭环境的客观事实（变化事件、氛围、互动模式等）
- 第 ⑬ 部分的「问题归因分布」「夫妻分歧的具体内容」「已尝试方法的效果」等**事实性**信息
- 改进建议、行动方案

### Layer B：仅供内部使用的画像（**绝不**出现在报告文字中）
基于第 ⑬ 部分以及全卷的回答模式，内部推断填卷人的：
- **倾向性**：完美主义型 / 焦虑型 / 控制型 / 放养型 / 自责型 / 否认型 / 平衡型 等
- **当前承载力**：高 / 中 / 低（受睡眠、压力、情绪、伴侣关系等影响）
- **觉察水平**：高觉察（能看到自身因素）/ 中觉察 / 低觉察（全部归因孩子或外部）
- **代际模式**：是否在重复或反向对抗自己被对待的方式
- **夫妻协同度**：高共识 / 有差异但能讨论 / 明显冲突

这些画像 **只用来调整报告的语气、节奏、切入点和优先级**，不作为内容呈现。

---

## 2. 严禁事项（硬规则）

报告中绝对不可以出现：

- ❌ 任何对填卷人的人格标签（如"您是焦虑型家长"、"您比较完美主义"、"您觉察度高/低"）
- ❌ 任何形式的"诊断"填卷人（如"您可能也有……倾向"、"建议您先处理自己的……"作为开篇）
- ❌ 把问题责任比例直接抛回填卷人（如"其实问题主要在您身上"）
- ❌ 用专业心理学术语去命名填卷人的状态（投射、防御、退行等）

报告中允许且应该出现：
- ✅ 对孩子的客观行为描述与机制解释
- ✅ "在您家庭目前的节奏下，建议优先尝试……"这类**情境化**建议
- ✅ 涉及家长自身时，用**邀请式**而非**诊断式**语言：
  - 邀请式："如果您愿意，可以观察一下自己在 X 场景下的反应……"
  - 诊断式（禁用）："您的反应模式属于 X 类型……"

## 3. 画像 → 语气调整对照表

| 内部画像 | 报告语气调整 |
|---------|------------|
| 高焦虑 / 当前承载力低 | 减少建议条目数量（≤3 条优先级最高的）；强调"先做一件事"；语气松弛、不紧迫 |
| 完美主义倾向 | 主动给出"足够好"的标准；明确告知哪些可以暂不处理；避免列长清单 |
| 自责 / 内疚明显 | 开篇先呈现孩子身上**已经在发挥作用的资源**；机制解释多用"大脑/发育/环境"等去人格化归因 |
| 否认 / 全归因孩子 | 多用孩子的**具体行为细节**而非概念；让数据自己说话；不直接对抗其归因 |
| 夫妻分歧明显 | 给出"双方都能接受的最小公约数行动"；避免站队；用"家庭系统"而非"某一方"措辞 |
| 高觉察 / 平衡型 | 可呈现更完整的机制分析与中长期方案；可包含家长自我观察建议 |
| 代际严厉模式 | 在亲子互动建议中明确避免"重复"路径；但**不**点出代际成因 |
| 隔代/老师卷入 | 建议中包含"如何与配偶/长辈/老师对齐"的脚本，而非只对填卷人布置任务 |

---

## 4. 第 ⑬ 部分的特殊处理

第 ⑬「视角与归因」部分是**画像主要来源**，处理时：

1. 全部回答仅进入 Layer B（内部画像），**不**直接复述给填卷人
2. 「责任比例百分比」用于推断觉察水平，但**不**在报告中提及具体数字
3. 「与配偶的分歧」（13.4）若有内容，可在建议部分以"家庭内部需要先对齐的几点"形式**间接**回应，但不引用原话
4. 「此刻心情」「自身状态」（13.5/13.6）用于决定建议的强度和数量，**不**在报告中评论
5. 「身体最先反应」「小时候被对待的方式」（13.7/13.8）用于个性化亲子互动脚本，**绝不**作为分析对象出现

---

## 5. 报告结构建议

按以下顺序输出（具体章节数视画像调整）：

1. **画像层级先做**：先在内部生成 Layer B 画像 → 决定本次报告的"语气档位"
2. **孩子侧观察小结**：客观、去标签
3. **机制解释**：从生理 / 认知 / 环境 / 心理多角度，使用"大脑/发育"等去人格化语言
4. **优先级行动**（数量按承载力调整）：每条都是可执行的小步骤
5. **家庭层面的可选建议**：用邀请式语言，强调"如果您愿意"
6. **下一步建议**：观察什么、何时复评

## 6. 自检清单（生成报告后必须过一遍）

- [ ] 是否有任何句子在描述"填卷人是什么样的人"？→ 必须删除或改写
- [ ] 是否使用了诊断式动词（"您是"、"您属于"、"您倾向于"）？→ 改成观察式或邀请式
- [ ] 建议条目数量是否匹配填卷人当前承载力？
- [ ] 是否在不点名的前提下，照顾到了夫妻分歧 / 代际模式 / 当前情绪？
- [ ] 报告的"重心"是否在孩子和家庭系统上，而不是在填卷人身上？
